# 布丁貓的失控舞台 · M3.3 三項舞台任務

桌面瀏覽器的 2.5D 跳躍遊戲。使用者已確認 M1、M2 可操作，目前可自由選擇佳音寶寶的三道具尋寶、佳音女寶寶的燈光記憶、法蘭奇的音響救援任務。一次只進行一項，完成分數各自保存。

## 道具任務

1. 靠近佳音寶寶，按 **E** 或互動按鈕，選「接受任務，開始計時」。
2. 往右跨越箱子與缺口，收集一樓右端的金色星星；從右側箱子、紫色踏階跳上二樓，取得右側粉紅寶石，再越過上層缺口取得左端藍色圓環。
3. **找齊 3 個**後帶回佳音寶寶身旁，按 **E → 交還全部 3 個道具**。可以自行選擇收集順序，少任一個都不能完成。

## 燈光任務

1. 找佳音女寶寶按 E，選「接受任務，觀看燈光」。
2. 記住 A／B／C 踏板的亮起順序；每次接受會重新洗牌，示範期間暫停移動，鏡頭對準三個踏板。
3. 示範結束後依序踩踏板。用跳躍避開目前不該踩的踏板；走上或落在踏板都算一次，站著不動不會連續觸發。示範結束時若已站在踏板上，需先離開再踩回，避免自動判錯。
4. 三個全對便自動完成並恢復舞台燈光。踩錯扣一次機會、結束本次挑戰，可找佳音女寶寶重試。

A 在左側地面、B 在矮箱上、C 在較高箱上；示範會同步顯示顏色與字母，結束後隱藏答案。尚未接燈光任務時，踏板不判定對錯。

## 音響任務：法蘭奇，遙控器還來！

1. 靠近音控台按 **E** 接任務，法蘭奇會以移動標示牌帶著遙控器往右逃跑（角色模型尚待提供）。
2. 追過右側路線，躲開法蘭奇啟動的兩座喇叭；綠色為安全空檔、黃色為預警、紅色為低音波。可等待綠色或跳過紅色區域，文字與倒數不依賴聲音。
3. 法蘭奇約 8.5 秒到達最右端後會停下等候。靠近終點、落地並按 **E／「拿回遙控器」按鈕** 才能取回；只走近不會自動拾取，也不能在途中提前拿走。
4. 帶著遙控器避開回程音波，回到原位的**音控台**，按 **E → 交還遙控器**完成。
5. 碰到音波扣一次共用機會並結束本次挑戰；法蘭奇與遙控器回到音控台，可重新接受。

保留音響 50 秒及既有計分。音波預警 1.2 秒、固定週期 4.8 秒、兩座錯開 1.6 秒；標示牌移動速度 1.8 單位／秒，屬試玩數值。對話、結果及隱藏分頁會暫停追逐與音波；未進行音響任務不會被音波扣次，完成後喇叭停止失控。

## 共用操作與規則

方向鍵／A D 移動，空白鍵跳躍，R 返回起點。紫色平台可從下方跳上，鏡頭會跟隨高度。對話按 Esc 或「繼續探索」關閉。

全場共用 **3 次失誤機會**。掉落、超時、任務中按 R 、燈光踩錯或碰到音波各扣一次。道具失敗會全部歸位，燈光失敗可重新觀看示範；音響失敗將遙控器歸位；三項都可重接。失敗保留其他完成分數；機會耗盡後重新開始會清除三項進度與分數。
自由探索不計時；對話、結果視窗及切換分頁暫停。完成任務後的分數保留於本場，重新整理頁面會清除。

目前試玩值：**道具 60 秒、燈光 45 秒（含約 5.2 秒示範）、音響 50 秒、各完成 500 分、每剩餘整秒加 10 分**，集中於 `src/mission.js`、`src/lights.js` 與 `src/audio-mission.js`，尚可依試玩調整。
三項全部完成後顯示各項分數與總分，按「重新開始」開啟新的一場。尚無骨架動作或影片彩蛋。

## 開發與驗證

使用 Node.js 24 LTS（`.nvmrc`）：

```bash
npm ci
npm run dev
```

開啟終端顯示的網址；首頁為遊戲，`/viewer.html` 為 M0 GLB 素材檢視器。

```bash
node tests/physics.test.js
node tests/mission.test.js
node tests/npcs.test.js
node tests/lights.test.js
node tests/audio.test.js
npm run build -- --base=/pudding-cat-game/
```

目前 26 項自動測試涵蓋既有兩項玩法、兩座音波完整預警／碰撞、法蘭奇移動及終點等待、手動拾取與高度門檻、遙控器實際物理往返路線、失敗保分，以及三個任務的六種完成順序與總分重置。Chromium 使用僅在測試回應注入的位置資料，檢查音控台接任務、追逐／預警顯示、對話暫停、走近不自動拾取、E 取回、交還計分及失敗重試；正式程式不包含測試入口。
`src/physics.js` 調整場地及移動，`src/npcs.js` 管理 NPC，`src/mission-ui.js` 管理對話，`src/mission.js` 管理共用狀態與結算。燈光及音響各有獨立規則模組與場景顯示模組。

## 素材與後續範圍

`public/assets/characters/` 包含布丁貓、佳音寶寶、佳音女寶寶 GLB；現有缺少貼圖的呈現已獲接受。法蘭奇使用文字牌預留，模型待提供。兩支 MP4 與觸發條件仍待提供／確認。
模型以整體位移呈現，不假設具備角色動畫；各骨架不同，Shape Key 相容性需以檢視器實測。

新 `.blend` 素材須先按 `AGENTS.md` 唯讀稽核，再匯出獨立 GLB，保留原始檔。稽核範例（需要 Blender）：

```bash
blender --background /path/to/source.blend --python scripts/audit_blend.py -- --output /path/to/audit.json
```

匯出時選必要角色網格及骨架，保留蒙皮與 Morph Targets，排除廣告動畫；檢查貼圖與 Driver 相容性。GLB 可拖入 `/viewer.html` 檢查網格、骨架、Shape Keys 和動畫資料。
詳細規劃見 `GDD.md`、`PLAN.md`。目前完成 M3 三項任務試玩版，玩法細節可後續調整；影片彩蛋條件仍待確認。
