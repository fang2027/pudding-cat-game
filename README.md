## 道具任務

1. 靠近佳音寶寶，按 **E** 或互動按鈕，選「接受任務，開始計時」。
2. 往右跨越箱子與缺口，收集一樓右端的金色星星；從右側箱子、紫色踏階跳上二樓，取得右側粉紅寶石，再越過上層缺口取得左端藍色圓環。
3. **找齊 3 個**後帶回佳音寶寶身旁，按 **E → 交還全部 3 個道具**。可以自行選擇收集順序，少任一個都不能完成。

## 燈光任務

1. 找佳音女寶寶按 E，選「接受任務，觀看燈光」。
2. 共 **3 回合**：第一回合記住 **3 次**亮燈（每次間隔 1.4 秒）、第二回合 **4 次**（1.15 秒）、第三回合 **5 次**（0.9 秒）。每回合重新產生順序，三個踏板都會出現；後兩回合包含重複踏板。
3. 示範結束後依序踩踏板。用跳躍避開目前不該踩的踏板；走上或落在踏板都算一次，站著不動不會連續觸發。示範結束時若已站在踏板上，需先離開再踩回，避免自動判錯。
4. 同一踏板重複亮起時，需先離開再踩回，也可**原地跳一下**。站著不動不會自動提交第二次。
5. 前兩回合全對後顯示通過提示，停留 1.8 秒後自動示範下一回合；示範與換回合期間暫停移動，鏡頭對準踏板。
6. **三回合全對**才完成、恢復舞台燈光並計分。三回合共用 **75 秒**（包含示範及換回合），中途不重設倒數。踩錯扣一次機會、結束整項挑戰，可找佳音女寶寶重試，從第一回合開始。

A 在左側地面、B 在矮箱上、C 在較高箱上；示範會同步顯示顏色與字母，結束後隱藏答案。尚未接燈光任務時，踏板不判定對錯。

只有燈光任務進行時，踩住踏板才會同步點亮腳下踏板、上方燈泡及對應卡片，並顯示光圈。自由探索、其他任務及燈光任務結束後，踩踏都不會觸發亮燈、下壓或光圈。正確輸入會顯示「✓ 踩對」及已完成步數，離開踏板後保留約 0.7 秒回饋。踩錯會在結果視窗指出踩到的字母。示範仍只依原順序亮燈，不受角色腳下位置影響；跳過踏板不算踩踏。完成任務後維持固定的恢復照明，與踩踏無關。

## 音響任務：法蘭奇，遙控器還來！

1. 靠近音控台按 **E** 接任務，法蘭奇會帶著遙控器逃跑，沿路播放原角色的跑步動作。
2. **第一段 · 矮箱攔截**：跨過缺口，跳上一樓右側矮箱（x=5.6），靠近並按 **E 攔住法蘭奇**。他假裝交還，啟動兩座喇叭並逃往最右端。
3. **第二段 · 右端再追**：追到一樓最右端（x=14.5），落地按 **E** 再次攔住他。他會往二樓逃跑，畫面提示登台路線。
4. **第三段 · 二樓奪回**：從右側矮箱、高箱、紫色踏階跳上二樓右側平台（x=6.8）。靠近並落在同一層，按 **E／「拿回遙控器」按鈕** 才能取回。
5. 帶著遙控器回到原位的**音控台**，按 **E → 交還遙控器**完成；可沿二樓往左跳，再從箱子旁落回一樓。

每段法蘭奇抵達後會等待；只走近不會自動推進，也不能從樓下或在逃跑途中拿走遙控器。前兩次攔截後各有 1.2 秒反應停留及文字回饋，進度卡片顯示目前追到第幾次，金色光圈標示本段目的地。第三次取得遙控器後才進入交還階段，中途不計分。

保留音響 **50 秒**及既有計分。依使用者加速回饋，移動速度由 2.8 調為 3.6 單位／秒（約快 29%）；喇叭在第一次攔截後才啟動，綠色安全、黃色預警 1.2 秒、紅色低音波，可等安全空檔或跳過。固定週期 4.8 秒、兩座錯開 1.6 秒；第二次攔截不重置音波週期。以上均為試玩數值。
碰到音波扣一次共用機會並結束挑戰；失敗會重置全部三段進度、遙控器、喇叭與提示，可回音控台重接。對話、結果及隱藏分頁會暫停追逐與音波；未進行音響任務不會被音波扣次，完成後喇叭停止失控。

## 共用操作與規則

方向鍵／A D 移動，空白鍵跳躍，R 返回起點。紫色平台可從下方跳上，鏡頭會跟隨高度。對話按 Esc 或「繼續探索」關閉。

全場共用 **3 次失誤機會**。掉落、超時、任務中按 R 、燈光踩錯或碰到音波各扣一次。道具失敗會全部歸位，燈光失敗可重新觀看示範；音響失敗將遙控器歸位；三項都可重接。失敗保留其他完成分數；機會耗盡後重新開始會清除三項進度與分數。
自由探索不計時；對話、結果視窗及切換分頁暫停。完成任務後的分數保留於本場，重新整理頁面會清除。

目前試玩值：**道具 60 秒、燈光三回合共 75 秒（含三次示範及換回合）、音響 50 秒、各完成 500 分、每剩餘整秒加 10 分**，集中於 `src/mission.js`、`src/lights.js` 與 `src/audio-mission.js`，尚可依試玩調整。
三項全部完成後顯示各項分數與總分，按「重新開始」開啟新的一場。布丁貓已有四足走路循環，依回饋加大步幅與抬腳幅度，前後腳先向前伸再接地，落地後往後推，減少原地踏步感；尾巴站姿微微上翹，走路時形成逐節傳遞的 S 型擺動；身體隨步伐明顯上下起伏並輕輕側擺，呈現輕快感，腳部 IK 補償讓落地腳掌維持貼地。實際落地移動時踏步，停止或撞箱平順回站姿。跳上／跳下平台時身體隨拋物線上升後仰、頂點近水平、下降前傾；前腳收起，後腿向後伸展，下降時稍微回收並準備接地，接地時蹲低緩衝後銜接走路或站姿；直接走出平台邊緣則進入下落姿勢。對話、結果、燈光示範／換回合及切換分頁時暫停，重生重置。影片彩蛋尚未加入。

## 素材與後續範圍

`public/assets/characters/` 包含布丁貓、佳音寶寶、佳音女寶寶 GLB。佳音寶寶與女寶寶已依原始 Blender 材質恢復深棕色眼睛、黑色睫毛與衣服 J 標誌；服裝保留配色、使用固定粗糙度，依使用者要求省略布料紋理。貼圖內嵌於 GLB；衣服另烘焙原始實體化與算繪等級 2 的細分效果，修正胸口及腰部穿模。保留原有頭部／身體網格、骨架及表情，服裝沿用原 UV 與插值後的四組有效蒙皮權重。法蘭奇已匯出為兩個網格、48 根骨架及六個表情目標，保留 UV，貼圖待補；跑步取自來源 277–404 幀並整理為約 4.23 秒循環，已整合三段逃跑路線。移動時跑步、等待時回站姿、按路線轉向，對話與結果暫停、失敗重置。兩支 MP4 與觸發條件仍待提供／確認。
布丁貓由 `src/pudding-walk.js` 驅動已核對的四足變形骨鏈，保留腳掌方向與原有表情；動畫相位依實際位移推進，尾巴保留段長並逐節形成相反曲率。`src/pudding-jump.js` 依垂直速度、離地和接地訊號控制跳躍與有限時間的落地緩衝，身體律動只影響模型內部展示層，不改變遊戲位置、速度或碰撞。法蘭奇由 `src/frankie-run.js` 播放自己的骨架動作，兩位寶寶尚未新增骨架動畫；各角色骨架不同，不共用動作。開發中可開 `/source_assets/pudding-walk.html` 觀察走路，或 `/source_assets/pudding-jump.html` 切換跳上、走下、跳下平台，均可暫停、慢速及拖曳換視角。

新 `.blend` 素材須先按 `AGENTS.md` 唯讀稽核，再匯出獨立 GLB，保留原始檔。稽核範例（需要 Blender）：

```bash
blender --background /path/to/source.blend --python scripts/audit_blend.py -- --output /path/to/audit.json
```

匯出時選必要角色網格及骨架，保留蒙皮與 Morph Targets，排除廣告動畫；檢查貼圖與 Driver 相容性。GLB 可拖入 `/viewer.html` 檢查網格、骨架、Shape Keys 和動畫資料。
詳細規劃見 `GDD.md`、`PLAN.md`。目前完成 M3 三項任務試玩版，玩法細節可後續調整；影片彩蛋條件仍待確認。

兩位寶寶的材質修正可重做：先以 `scripts/audit_character_materials.py` 在 Blender 產生唯讀 JSON 稽核，再執行 `node scripts/repair-character-materials.js 稽核.json 貼圖資料夾 輸入GLB資料夾 獨立輸出資料夾`。眼睛原用反射座標漸層，網頁版改用原眼睛節點的深棕色與粗糙度；衣服中性灰疊加不改變標誌色彩，因此可直接使用原標誌貼圖。原始 `.blend` 和貼圖不覆寫。

服裝幾何另由 `scripts/export_clothing_geometry.py` 在獨立 Blender 程序讀取來源檔與未烘焙服裝的 GLB，使用 `--source 原檔.blend --input-dir 輸入GLB資料夾 --output clothing.geometry.json` 輸出。此步停用骨架變形，只計算服裝實體化／細分、UV、法線及權重；接著 `node scripts/replace-clothing-geometry.js clothing.geometry.json 輸入GLB資料夾 獨立輸出資料夾` 替換衣服。不要對整個角色統一套用修改器；臉部 Shape Keys 與原始骨架保持不變。
